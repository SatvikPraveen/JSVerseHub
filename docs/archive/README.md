# Archived documents

This folder holds historical planning, status and summary documents from the v1.0.0 phase of JSVerseHub
(execution plans, completion checklists, status reports, roadmaps and similar). They are retained for
provenance, so that the project's history and the reasoning behind earlier choices remain traceable, but
they have not been updated since that phase and are **not** accurate descriptions of the current system:
file layouts, feature lists, test counts and "completion" claims in these documents may all be out of date.
For a current description of the platform, read the top-level [README.md](../../README.md); for the learner
models, analytics schema and evaluation notes, see [docs/research/](../research/); for the reasoning behind
the main technical decisions, see [docs/adr/](../adr/).
